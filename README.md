**volUP v1.5 Master Edition** is the ultimate Chrome extension that amplifies web audio up to **1000% (10x)** with zero distortion, features a **10-Band Pro Equalizer**, **Sleep Auto-Off Timer**, **Stereo-to-Mono Converter**, **Vocal Clarity Filter**, **On-Screen Display (OSD)**, **Ear Safety Lock**, **Saved Domain Rules Manager**, **Import/Export Settings Backup**, **Multi-Tab Audio Mixer with Tab Mute**, **Smart Audio Profiles**, and **Global Keyboard Shortcuts**.

---

## ✨ Master Edition Features (v1.5.0)

- **🚀 Up to 1000% (10x) Turbo Boost:** Safely amplifies low-volume web audio feeds beyond limits.
- **⚡ On-Screen Display (OSD) Toast:** Sleek floating volume badge (`🔊 350%`) appears over web pages when using keyboard shortcuts.
- **⏱️ Sleep Auto-Off Timer:** Set a timer (15m, 30m, 45m, 60m) to automatically mute audio when falling asleep.
- **🎧 Stereo to Mono Converter:** Mixes L & R audio channels into single earbud feed.
- **🎙️ Vocal Clarity Filter:** Boosts speech frequencies (`1.5kHz - 3.5kHz`) for crystal clear movie dialogue.
- **🛡️ Ear Protection Safety Lock:** Option to cap max volume at 400% for hearing safety.
- **🎛️ 10-Band Pro Studio Equalizer:** Precision frequency control (31Hz to 16kHz) + 5-Band mode.
- **🌐 Saved Domain Rules Manager:** Delete or clear custom site volume rules.
- **📥 Import / Export Settings Backup:** Backup your custom EQ presets and site rules to JSON file.
- **🎛️ Multi-Tab Volume Mixer with Tab Mute:** Mute/unmute individual tabs or switch focus.
- **🎨 Visualizer FX Themes:** Neon Waves, Pulse Ring, and LED VU Meter.
- **⌨️ Global Keyboard Shortcuts:** `Alt+Shift+Up`, `Alt+Shift+Down`, `Alt+Shift+M`.
- **🔒 100% Privacy Focused:** Local storage only ([Privacy Policy](PRIVACY.md)).
